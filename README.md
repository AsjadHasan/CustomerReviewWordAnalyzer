# CustomerReviewWordAnalyzer
Ask a shop owner how many customer reviews they want to analyze, then ask them to type in each review. Print the top 3 most frequent words across all reviews (case-insensitive, ignoring punctuation and common stop words like 'the', 'is', 'and').
<br>
Topics covered:
input(), int(), variables, strings, string methods, lists, sets, for loop, if condition, membership operator, append(), Counter, most_common(), tuples, punctuation handling.
